UI GAP AUDIT · ANDROID

The tokens landed. The screens didn't.

Your Flutter app is not off-guide because someone used the wrong colours. lib/theme.dart is a careful, accurate port of the deep-ink + gold system — every hex, every type style, both palettes, the tint map, the CBT palette. The port then stopped after tokens, fonts, brand assets and the splash. Every screen below it still renders the layout that was designed for the old teal system, now wearing gold paint.

The repo says so itself. docs/DESIGN-GUIDE-PORT.md ends with a seven-item Not done list, and that list is exactly what a student notices.

THE THREE-LINE PROOF

Declared and referenced by nothing
AppTheme.goldGradient, AppText.hero, AppColors.chrome and AppColors.nav exist in theme.dart and appear in zero widgets. Those four tokens are the guide's gold CTA, its 33px display headline, its branded header and its translucent tab bar — four of the five things you see first.
Comments that still describe the old system
PrimaryButton in widgets.dart is documented "Solid brand teal, no gradient, no glow" and fills flat #F5A623 at 10px radius. ProgressBar: "the gradient is gone." Both are pre-guide decisions that survived the retheme untouched.
Devanagari is bundled and unreachable
Noto Sans Devanagari ships in pubspec.yaml and is wired only as a fallback. No Flutter surface ever asks for Hindi, and the EN/हिं toggle the guide puts on every pre-auth screen does not exist in the app at all. The web SPA has both.

FOUR PATCHES, WRITTEN AND IN THIS PROJECT

Drop-in Dart. Nothing here touches behaviour, routing, auth or the CBT engine.

01
dart/practest_guide_widgets.dart
The primitives, and the highest-leverage change on the list: GoldButton (the real gradient, 16px, glow), GhostButton, EyebrowPill, ChromeHeader, GuideCard, TickedClaim. Swapping these repaints every screen at once.
02
dart/i18n.dart
The EN/हिं layer, persisted to SharedPreferences, strings ported from app/src/lib/i18n.js so phone and browser say the same words. Scoped to splash, welcome, login, nav and brand copy; API text stays as the server sends it.
03
dart/welcome_screen.dart
The welcome screen rebuilt to the guide, replacing intro_screen.dart at the same route. Needs assets/hero/welcome.jpg; falls back to the guide's radial ink until that photograph exists, so it is never broken — but it is not the design until you drop the image in.
04
dart/shell_five_tab.dart
Five tabs, the nav ground, a flagged Store stub matching the web's, and the lucide glyph name for each tab so the icon swap is mechanical. The four-tab reasoning is kept in the comment rather than deleted.
