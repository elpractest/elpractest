Web app ↔ Flutter app — one design, both themes

Checked both codebases directly: app/src/index.css (web) and lib/theme.dart (Flutter) already share the exact same tokens — same hex values, same dark/light pairs, same Sora + Plus Jakarta Sans + JetBrains Mono stack, same CBT status colours. That part is not the gap.

WHERE THEY ACTUALLY DIVERGE
1) Icons — the phone app draws Material glyphs (filled home/description/school/bag/person + a sparkle FAB); the web draws lucide-style stroke icons (home/target/book‑open/shopping‑bag/user + a bot‑face FAB). 2) Screen layout — the phone's Welcome, Login, Home, Vajini, Notifications, Search and Store screens are still mid‑port to this design system (per the repo's own DESIGN-GUIDE-PORT.md); the web is the finished reference for those screens, not the other way round. 3) Responsiveness — the web has no tablet‑specific layout, only a phone view and a ≥1024px sidebar; the phone app, being native, always fills its one screen size correctly.

So "full similarity in both day and night mode" below means: same icon glyphs, same colour tokens rendered identically in dark AND light on every real screen, and a genuine phone → tablet → desktop responsive system on the web — with zero new buttons, fields or features.
